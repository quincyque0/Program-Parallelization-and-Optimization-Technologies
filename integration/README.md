Вся математическая часть кода строится на трех компонентах: вычислении точного значения через первообразную, приближенном интегрировании методом парабол и оценке погрешности по правилу Рунге.

---

### 1. Точное значение интеграла (Формула Ньютона-Лейбница)

Интегрируемая функция $g(x)$ сконструирована как аналитическая производная функции $f(x)$:

$$f(x) = \frac{x^4}{0.5x^2 + x + 6}$$

Дифференцируя $f(x)$ по правилу производной частного $\left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2}$:

* $u = x^4 \implies u' = 4x^3$
* $v = 0.5x^2 + x + 6 \implies v' = x + 1$

$$g(x) = f'(x) = \frac{4x^3(0.5x^2 + x + 6) - x^4(x + 1)}{(0.5x^2 + x + 6)^2}$$

Раскрывая скобки в числителе:


$$4x^3(0.5x^2 + x + 6) - x^4(x + 1) = 2x^5 + 4x^4 + 24x^3 - x^5 - x^4 = x^5 + 3x^4 + 24x^3 = x^3(x^2 + 3x + 24)$$

Получаем в точности функцию из кода:


$$g(x) = \frac{x^3(x^2 + 3x + 24)}{(0.5x^2 + x + 6)^2}$$

Следовательно, точное значение определенного интеграла на отрезке $[a, b]$ вычисляется без приближений:


$$I_{\text{точн}} = \int_{a}^{b} g(x)\,dx = f(b) - f(a)$$

### 2. Составная формула Симпсона (Метод парабол)

Отрезок $[a, b]$ разбивается на $n$ равных элементарных отрезков (где $n$ обязательно четное), шаг сетки:


$$h = \frac{b - a}{n}, \quad x_i = a + i \cdot h \quad (i = 0, 1, \dots, n)$$

На каждой сдвоенной паре отрезков $[x_{2k-2}, x_{2k}]$ подынтегральная функция интерполируется параболой (многочленом второй степени Lagrange), проходящей через три точки: $(x_{2k-2}, g_{2k-2})$, $(x_{2k-1}, g_{2k-1})$ и $(x_{2k}, g_{2k})$.

Интеграл от параболы на таком сдвоенном шаге длиной $2h$ равен:


$$\int_{x_{2k-2}}^{x_{2k}} g(x)\,dx \approx \frac{h}{3} \big( g(x_{2k-2}) + 4g(x_{2k-1}) + g(x_{2k}) \big)$$

Суммируя по всем подотрезкам от $k = 1$ до $n/2$, получаем составную формулу:


$$I_n \approx \frac{h}{3} \left[ g(a) + g(b) + 4 \sum_{\substack{i=1 \\ i \text{ нечетное}}}^{n-1} g(x_i) + 2 \sum_{\substack{i=2 \\ i \text{ четное}}}^{n-2} g(x_i) \right]$$

### 3. Оценка практической погрешности (Правило Рунге)

Остаточный член (теоретическая погрешность) метода Симпсона пропорционален четвертой степени шага:


$$R_n \approx C \cdot h^4 = O(h^4)$$


где $C$ — константа, зависящая от четвертой производной $g^{(4)}(\xi)$.

При переходе от $n$ шагов к $2n$ шагам величина шага уменьшается вдвое ($h_{2n} = \frac{h_n}{2}$):


$$I_{\text{точн}} \approx I_n + C h_n^4$$

$$I_{\text{точн}} \approx I_{2n} + C \left(\frac{h_n}{2}\right)^4 = I_{2n} + C \frac{h_n^4}{16}$$

Вычитая второе выражение из первого:


$$0 \approx (I_n - I_{2n}) + C h_n^4 \left(1 - \frac{1}{16}\right) \implies C h_n^4 \cdot \frac{15}{16} \approx I_{2n} - I_n$$

Отсюда погрешность более точного приближения $I_{2n}$ выражается как:


$$R_{2n} = C \frac{h_n^4}{16} \approx \frac{\vert{}I_{2n} - I_n\vert{}}{15}$$

В общем виде для метода порядка $p$ знаменатель равен $2^p - 1$. Для метода Симпсона $p = 4$, поэтому знаменатель равен $2^4 - 1 = 15$. Процесс измельчения сетки продолжается до выполнения условия:


$$\frac{\vert{}I_{2n} - I_n\vert{}}{15} \le \varepsilon$$
